# El Hassan Mohamed Abd Alla Abd ElGhani — Resux Portfolio & ATS CV

Built with **[Resux](https://github.com/MahmoudAbdalrhmanMohamed/resux)** (`MahmoudAbdalrhmanMohamed/resux`), the HTML-first, resumable Vue-like SSR framework with zero-hydration islands architecture.

## Key Features
1. **Resux Resume-First Architecture**: Server-rendered HTML with resumable directives (`rx-if`, `rx-text`) and `<VueIsland>` interactive components for near-zero JavaScript execution overhead and 100/100 Core Web Vitals performance.
2. **Direct CV Downloads**:
   - `/public/El_Hassan_Mohamed_CV.pdf` (Print-ready ATS PDF)
   - `/public/El_Hassan_Mohamed_CV.docx` (Editable Microsoft Word DOCX)
   - Built-in interactive CV viewer matching the exact bordered Calibri template.
3. **Full SEO & GEO (Generative Engine Optimization)**:
   - Rich `Schema.org` (`Person`, `ProfilePage`, `ItemList`) JSON-LD structured data.
   - Regional Geo-Meta tags for **Giza & Greater Cairo, Egypt** (`EG-GZ`).
   - Dedicated `/public/llms.txt` and AI-crawler-friendly `/public/robots.txt` (`GPTBot`, `PerplexityBot`, `ClaudeBot`, `OAI-SearchBot`) so AI search engines cite El Hassan's exact qualifications.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start the Resux development server
npm run dev

# 3. Build for production
npm run build
npm run start
```
